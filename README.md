# Hi there 👋 I'm Arda Cem Bilecan

**Data Engineer** · ETL/ELT · Data Migration & Warehousing
📍 Eskişehir, Turkey

I design, migrate and tune data pipelines and warehouses. Over 4+ years I have worked across **insurance, telecommunications, energy and manufacturing**, moving legacy ETL into modern, cloud-ready architectures. My background in machine learning and AI still shapes how I build: today I also design AI agents that speed up data-integration development.

## 🔧 What I do

- 🔄 **Migrate legacy ETL/ELT** (IBM DataStage → Talend, PostgreSQL → Snowflake) across Oracle, DB2/AS400, MongoDB, PostgreSQL and Hadoop-based environments
- ⚡ **Tune pipelines**: parallelized subjobs, staging-table patterns, Talend configuration tuning, Qlik Replicate task optimization
- 🏗️ **Build ELT on Snowflake** with dbt and Snowpark, orchestrated and version-controlled with Git
- 🤖 **Apply AI to data integration**: agents that generate and streamline Data Integration / Data Flow jobs
- 🏢 **Data warehousing on SAP** (S/4HANA, HANA, BW, Dataphere) from earlier consulting work
